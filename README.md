# Joshua Karisa — portfolio

A static, responsive portfolio for [karisajoshua.github.io](https://karisajoshua.github.io/). It presents selected public work, an experience-based toolkit, and ways to connect.

## Run locally

Open `index.html` in a browser, or serve this directory with `python3 -m http.server 8000` and visit `http://localhost:8000`. No build step or dependencies are required.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. The page contains no client-side secrets or backend services. Project visuals are CSS illustrations, not screenshots of live systems. Project status descriptions should be updated as implementations evolve.

## Accessibility

The page uses semantic sections, keyboard focus states, a skip link, responsive layouts, and reduced-motion support.
